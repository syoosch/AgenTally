# AgenTally 用户手册

[English](USER_GUIDE.md) | **简体中文**

本文说明当前 Stable 应用的主要使用方式。应用界面目前仅提供简体中文。

## 安装与启动

1. 打开[最新 GitHub Release](https://github.com/syoosch/AgenTally/releases/latest)；
2. 下载 Windows x64 安装程序和与它同名的 `.sha256` 文件；
3. 按 [README](../README.zh-CN.md) 中的步骤校验文件后运行安装程序。安装不需要
   管理员权限，也不要求预装 .NET；
4. 如果 SmartScreen 显示“未知发布者”，请先确认文件来自本仓库且 SHA-256
   一致，再决定是否运行。哈希不能证明发布者身份；
5. 从开始菜单启动 AgenTally。应用会自动发现受支持的本地 Agent 记录，并始终
   只读处理来源。

正常来源变化通常会在 30–60 秒内出现。如启动后没有数据，请查看
[使用帮助](../SUPPORT.zh-CN.md)。

## 页面导航

左侧导航包含：

- “概览”：总用量、等效价格、趋势、Agent/模型占比和热力图；
- “分析”：按 Agent、模型和项目查看详细构成；
- “项目”：查看逻辑项目、活跃情况、趋势、会话和用量构成；
- “会话”：查看根会话、Prompt 时间线、模型页签和可靠的逐调用明细；
- “数据来源”：查看已发现的来源实例及其兼容状态；
- “设置”：管理本地偏好和维护操作。

“设置”分为五类：

- “常规设置”：开机自启和界面刷新间隔；
- “数据与备份”：数据概览、备份、恢复、重扫、清除，以及高级数据库路径；
- “模型与计价”：查看和维护已经产生本地用量的模型价格；
- “隐私与安全”：查看本地只读和本地存储边界；
- “关于与更新”：版本信息和检查更新。

## 筛选和时间范围

“概览”“分析”“项目”和“会话”按页面能力共享 Agent、模型、项目和时间筛选。

时间选项包括“全部时间”“今天”“近 7 天”“近 30 天”“近 90 天”和“自定义”。
“全部时间”从当前筛选下第一条有效记录开始，到今天结束。

“自定义”使用 UI 启动时读取的 Windows 系统时区。依次选择开始日期、开始整点、
结束日期和结束整点。范围包含开始时刻但不包含结束时刻，即 `[开始, 结束)`；
结束必须晚于开始。完成结束整点后立即应用，取消会恢复此前生效的范围。

## 理解统计数字

- “总 Token”是来源能够可靠统计的总用量；
- 输入 Token 是来源报告的 prompt/input 用量；
- 缓存读取或命中只在来源可靠提供时显示；
- “未缓存输入”只在来源精确总量能够证明对应关系时计算；
- 缓存写入或创建只在来源可靠提供时显示；
- 输出 Token 是来源报告的生成/output 用量；
- “等效 API 价格”按明确的原始供应商公开 API 价格规则估算，不等同于供应商
  账单、订阅额度或实际付款金额。

界面严格区分以下状态：

- 零值：来源可靠报告或证明数值为 0；
- “未知”：当前无法确定状态；
- “不可取得”：本地来源没有可靠字段或唯一对应关系，AgenTally 不会猜测；
- “暂无数据”：当前页面或筛选没有匹配记录；
- “未计价”：已有 Token 用量，但没有命中精确价格规则。

## 项目、会话和 Prompt 时间线

来源能可靠提供规范化 Git 仓库身份时，AgenTally 按它建立逻辑项目；否则使用
完整工作目录，不会因为名称相似而合并不同路径。

“会话”保留来源、时间范围、实际工作目录、模型、Token 分类、总 Token 和等效
价格。只有来源提供可靠因果证据时，子会话才会归入根会话。

来源能可靠提供 Prompt 轮次时，AgenTally 只显示该轮第一条用户消息的受长度限制
摘要和可靠逐调用明细。应用不保存或展示完整 Prompt、回复、工具参数、工具输出、
附件路径或附件内容。归属不可靠时会显示不可取得，不进行猜测。

## 数据来源兼容状态

打开“数据来源”查看每个已发现来源：

- “完全兼容”：核心和分类指标的语义可靠；
- “部分兼容”：可靠指标继续显示，缺失或含义不明确的指标保持不可取得；
- “暂不兼容”：核心 Token 含义无法安全确定，因此停止该来源的统计；
- “仅结构发现”：可以发现会话或 Prompt 结构，但没有可靠的逐调用 Token 契约。

Agent 版本变化本身不会直接导致不兼容；只有必要的数据含义无法证明时才会停止。

## 模型与计价

进入“设置 → 模型与计价”。列表只包含已经产生本地用量的模型，以及为兼容既有
设置而保留的自定义价格。

内置价格是随 AgenTally 发布的离线快照。自定义价格只保存在本机，对未来记录和
当前仍未计价的记录具有最高优先级。修改或恢复价格不会重写已经计价的历史。没有
精确价格时，Token 仍会保留，价格显示为“未计价”。

价格的“生效日期”表示从所选日期的本地零点开始使用该费率；“价格历史”保留
此前和未来的日期规则。单模型“恢复默认”会结束所选日期起的自定义覆盖并取消
此后的计划覆盖，仍保留此前费率供晚导入调用使用。已计价金额不会因改价、目录
升级或重扫而重算。

DeepSeek Flash 和 V4 Pro 的内置峰谷价格按调用发生时的北京时间及随版本附带
的节假日表判断，目前覆盖 2026 年；保存自定义价格后使用固定覆盖费率。
缺少年表或无法证明历史费率时，估算可能保持部分计价或未计价。

## 备份与恢复

进入“设置 → 数据与备份”。

### 创建备份

1. 选择“立即备份”；
2. 按提示选择保存位置；
3. 将生成的备份作为私密本地数据妥善保存。

备份由 Core 创建一致性快照，包含统计、会话、Prompt 截断摘要、来源兼容状态与
游标、冻结价格和自定义价格；不包含 Agent 原始日志、完整 Prompt/回复、工具载荷、
附件、凭据、运行时文件或纯界面偏好。备份可能包含完整本地项目路径和会话名称。
AgenTally 不上传备份。

### 恢复备份

1. 选择“恢复备份”；
2. 选择 AgenTally 备份文件；
3. 阅读提示，仅在确实要替换当前统计时确认。

恢复前会校验压缩包、数据库、Schema、完整性和兼容频道。恢复是整库替换，不是
合并；校验或替换失败时会保留恢复前数据库和当前系统设置。

## 重新扫描和清除统计

进入“设置 → 数据与备份”：

- “重新扫描”会只读重扫全部受支持来源，安全补充仍能证明的数据，并保留只存在
  于 AgenTally 数据库中的历史；
- “清除全部统计”位于“危险操作”中，并要求二次确认。AgenTally 会先在每个当前
  来源末尾建立基线，再清除本地统计和已有事件计价绑定，之后只累计基线后的新
  内容。自定义模型价格会保留。

以后重扫可以恢复来源日志中仍存在的历史，但无法恢复已经从来源删除且又从
AgenTally 清除的历史。两项操作都不会修改 Agent 原始记录。

## 窗口、托盘和开机自启

- 最小化只会把 UI 保留在 Windows 任务栏；
- 关闭主窗口或按 Alt+F4 会退出 UI 进程，但 Core 和托盘继续统计；
- 双击托盘图标或选择“打开 AgenTally”，会重新打开“概览”页面；
- 在托盘选择“退出 AgenTally”，才会完全退出当前 Profile 的 UI 和 Core。

“开机自启”位于“设置 → 常规设置”，默认关闭。开启后，Windows 用户登录时只
启动 Core 和托盘，不会自动打开主窗口。

## 更新和卸载

新版安装器会在关闭已有程序和复制文件前拒绝用低版本覆盖高版本，允许同版本
修复及高版本升级。已发布的旧安装包本身不会追溯改变。

当前正式版本检查渠道尚未配置，自动和手动检查都不会发出版本请求。请从
[GitHub Releases](https://github.com/syoosch/AgenTally/releases/latest)
手动确认新版本。应用不会自动下载或安装更新。

卸载默认保留 Stable 数据库和设置。只有确实要删除 AgenTally 自有 Stable 数据、
日志和运行状态时，才选择明确的删除数据选项。保存在应用数据目录之外的备份和
全部 Agent 原始记录都不在卸载范围内。
